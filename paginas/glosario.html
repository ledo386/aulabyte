01 · Conceptos esenciales

Hardware

CPU
Componente que ejecuta instrucciones y procesa datos.
RAM
Memoria temporal utilizada por los programas en funcionamiento.
SSD
Unidad que guarda archivos de forma permanente usando memoria flash.
Periférico
Dispositivo conectado al ordenador, como un teclado o una impresora.

Ampliar información en componentes.

02 · Conexiones

Redes e Internet

Dirección IP
Identificador utilizado para dirigir paquetes de datos en una red IP.
Router
Dispositivo que comunica redes distintas y dirige el tráfico entre ellas.
DNS
Sistema que permite obtener direcciones IP a partir de nombres de dominio.
Wi-Fi
Tecnología que permite conectar dispositivos a una red sin cables.

Ver la explicación de redes.

03 · Páginas web

Desarrollo web

HTML
Lenguaje de marcado utilizado para organizar el contenido de las páginas web.
CSS
Lenguaje que define la presentación visual de un documento HTML.
JavaScript
Lenguaje de programación que puede añadir interactividad a una página.
Hipervínculo
Enlace que lleva a otro documento, recurso o apartado de una página.
