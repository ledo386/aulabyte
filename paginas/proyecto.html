01 · Presentación

¿Qué es AulaByte?

AulaByte es una web educativa de divulgación informática creada para Lenguajes de Marcas de 1.º DAM. Está dirigida a estudiantes que empiezan y a cualquier persona interesada en comprender la tecnología que utiliza a diario.

Su finalidad es explicar hardware, desarrollo web, redes y seguridad de forma sencilla y visual, combinando textos, imágenes, enlaces y un vídeo breve.

03 · Presentación

Diseño inspirado en una referencia

Para esta versión se ha observado la composición de la página de Marte proporcionada como ejemplo: una portada panorámica con título superpuesto, tres imágenes de acceso, una introducción sobre fondo oscuro, secciones de contenido alternando texto e imagen y un cierre destacado.

Se ha mantenido la temática de la informática, sustituyendo las fotografías espaciales por ilustraciones y esquemas tecnológicos locales. El código está separado en HTML para el contenido y un archivo CSS común para el diseño.

04 · Evolución

Posibles ampliaciones

  • Incluir formularios para proponer guías o enviar preguntas.
  • Añadir ejercicios y cuestionarios interactivos mediante JavaScript.
  • Ampliar las explicaciones con nuevas imágenes, vídeos y apartados.
  • Incorporar un buscador para el glosario.

El proyecto actual no necesita JavaScript para funcionar, y todos los recursos principales se guardan localmente.
