01 · Desarrollo web

Cómo se construye una web con HTML

HTML organiza el contenido mediante etiquetas. CSS se encarga de su apariencia: colores, tamaños, fondos y distribución. Esta propia web es un ejemplo de cómo se combinan.

Algunas etiquetas semánticas habituales son header (cabecera), nav (menú), main (contenido), section (apartado) y footer (pie).

Un ejemplo muy sencillo

<h1>Mi primera web</h1>
<p>Estoy aprendiendo HTML y CSS.</p>

Para ampliar conocimientos se puede consultar la documentación de HTML en MDN (enlace externo).

02 · Protección

Hábitos básicos de seguridad

No basta con instalar un antivirus. Una buena protección comienza con pequeños hábitos que podemos aplicar todos los días.

  • Usar contraseñas largas y distintas.
  • Activar la verificación en dos pasos.
  • Actualizar el sistema y los programas.
  • Desconfiar de mensajes urgentes y enlaces extraños.
  • Realizar copias de seguridad de archivos importantes.

Más información en INCIBE Ciudadanía (enlace externo).

03 · Conectividad

¿Cómo funciona una red doméstica?

Una red une dispositivos para compartir datos. El router conecta la red local con otras redes; la dirección IP identifica el destino de los paquetes y el DNS facilita acceder a servicios por su nombre.

  1. El dispositivo solicita un recurso.
  2. El router envía los datos hacia la red adecuada.
  3. El servidor responde y el dispositivo recibe la información.

El vídeo de la página principal representa ese recorrido de forma simplificada.

Si algún concepto te resulta desconocido, puedes ir al glosario de redes.
